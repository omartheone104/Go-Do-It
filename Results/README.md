This folder is to guide users through the steps to recreate all data and screenshots used in the final report of Go Do It.

To create the screenshots used, follow the steps in the main README file to run the app. Upon opening the application, you'll be greeted by the screen used in the first screenshot (you may have a different month and or year depending on when you open the application). For the second, create 2 tasks by doing the following: for the first, enter the title as "SWE II", and description as "Finish report". Then set the date to April 1st, 2026. Click "Save Task". For the second, repeat the process with title as "Interview", description as "At 12:00 pm", date as April 3rd 2026, and click on the category and change it to "Career". Then change the calendar's to April 2026, and the screen will show similarly to the second screenshot. To get the final screen shot, click on the Interview task in either the calendar or feed. Then click on the add subtask button on the editing pannel.

To create the table, you will first need to have Python installed on your system. You can to https://www.python.org/downloads to accomplish this. Then install Pip if you don't already have it with `python -m ensurepip --upgrade`, or other methods (a file with a python script that will download Pip can be located here: https://bootstrap.pypa.io/get-pip.py). Then make sure you are in the ./Results directory. You can then install the dependencies using `python -m pip install --requirement requirements.txt` (or `pip install --requirement requirements.txt` depending on system). Following this, simply run `python ./table.py` and the table will be displayed on your browser. The table will also be saved to this folder as `results_table.png`.
